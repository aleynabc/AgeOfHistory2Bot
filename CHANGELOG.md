# Changelog

## 1.1.2

- Hileler, Konsol ve Ayarlar sekmelerine dikey kaydırma çubuğu eklendi.
- Mouse tekerleği kaydırması tüm sekmelerde doğrudan ve hızlı çalışır.
- Dil değiştirildiğinde botun mevcut pencere konumu ve boyutu korunur.
- Oyun komutlarının ASCII-only olması çalışma zamanında da doğrulanır; Türkçe "ı" karakteri komutlara giremez.
- İstenen hile açıklamalarındaki 0.7 diplomasi, 750 nüfus, 600 ekonomi, teknoloji +X ve setarmy +X bilgileri güncellendi.

- Python paketleri build sırasında otomatik yükleniyor/güncelleniyor
- Geçersiz Inno Setup AppId GUID düzeltildi
